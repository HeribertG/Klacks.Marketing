### Teil 1: Allgemeine, branchenübergreifende Frankreich-USPs

1. Gesetzliche 35h-Woche, Überstunden ab Stunde 36: i.d.R. +25% für erste 8h, danach +50%, CCN kann ab +10% abweichen. Quelle: Code du travail Art. L3121-27 & L3121-36.
2. Modulation/Aménagement du temps de travail: Jahresarbeitszeit bis 1.607h, flexible Verteilung 0-48h/Woche, Jahressaldo löst Zuschläge/RTT-Tage aus. Quelle: Code du travail Art. L3121-41 bis L3121-47.
3. Tägliche Ruhezeit mind. 11h zusammenhängend, wöchentliche Mindestruhezeit 35h (24h Wochenruhe + 11h täglich). Quelle: Code du travail Art. L3131-1 & L3132-2.
4. CNIL: strenge Sanktionen bei unzulässiger Überwachung (Geolokalisation, biometrische Zeiterfassung) und algorithmischen Personalentscheidungen. Quelle: CNIL-Richtlinien / RGPD Art. 88.
